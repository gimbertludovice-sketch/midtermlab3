## 📋 Overview

This is a standalone HTML demo suite that simulates a Visual Studio IDE environment to showcase the full architecture and workflow of a **.NET Windows Forms + Microsoft SQL Server** Student Information System. Built for Midterm Lab 3 project defense.

---

## ✨ Features

- 🎙️ **Automated Voice Narration** — Browser speech synthesis walks through every step
- 🖥️ **VS Code / Visual Studio Themed UI** — Professional dark interface
- 📋 **7-Step Demonstration Flow**
  1. T-SQL Schema & DDL Execution
  2. Form Architecture & Data Binding
  3. CRUD Operations Execution
  4. Record Selection & Data Mapping
  5. Stream I/O & CSV Export
  6. Export Confirmation
  7. Verification & Validation
- 📊 **Live Console Log** — Simulated debug output updates in real time
- 📱 **Responsive Layout** — Works on desktop and tablet
- ⚡ **Zero Dependencies** — Single HTML file, no build tools needed


## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Frontend** | HTML5, Tailwind CSS 3, Vanilla JavaScript |
| **Database** | Microsoft SQL Server Express LocalDB |
| **Data Access** | ADO.NET (`SqlConnection`, `SqlCommand`, `SqlDataAdapter`) |
| **UI Framework** | .NET Windows Forms |
| **Export** | `System.IO.StreamWriter` → CSV Generation |


## 🚀 Quick Start

1. Download or clone this repository
2. Open `eventpro-lab-demo.html` in any modern browser (Chrome / Edge recommended)
3. Click **"Start Full Auto-Demo"** for the full narrated presentation
4. Or click any step in the left panel to explore manually
5. Use **"Stop Voice"** to pause audio
